# Module 06c: Hono & Modern Web Standards Runtimes

> Portable, lightweight Web Standards-based HTTP APIs with Hono and `@hono/node-server`.

---

## Module Overview

Hono represents the modern paradigm of server-side JavaScript: programming to standard `Request`/`Response` Fetch APIs rather than runtime-specific socket bindings. This module demonstrates building APIs with Hono, running them on Node.js via `@hono/node-server`, and deploying the same codebase across edge runtimes.
