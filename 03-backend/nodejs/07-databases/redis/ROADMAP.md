# Redis Sub-Track Roadmap

1. **Foundations**: Redis memory architecture, data types (Strings, Hashes, Lists, Sets, Sorted Sets).
2. **Node.js Integration**: `ioredis` connection pooling, pipeline batching, multi-exec transactions.
3. **Advanced Concurrency**: Distributed locks with Redlock, atomic Lua scripts, pub/sub.
4. **Streams & Queues**: Redis Streams consumer groups, BullMQ integration, Redis Cluster topology.
