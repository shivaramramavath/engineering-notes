# MongoDB Sub-Track Roadmap

1. **Foundations**: MongoDB architecture, BSON types, connection strings.
2. **Mongoose & Schema Design**: Modeling, validation, middleware, virtuals.
3. **Advanced Querying**: Aggregation pipelines (`$match`, `$group`, `$lookup`, `$unwind`).
4. **Operations & Scale**: Compound indexes, TTL collections, transactions, replica sets.
