# Module 11: Cloud & Microservices

Welcome to **Module 11: Cloud & Microservices**. This module covers cloud-native architectures with Spring Cloud: API gateways (Spring Cloud Gateway), fault tolerance with Resilience4j (circuit breakers, rate limiters, retries), distributed tracing with Micrometer Tracing, service discovery, distributed config, and Kubernetes-native configurations.
