# Module 16: Spring AI

Welcome to **Module 16: Spring AI**. This module explores modern Artificial Intelligence integration within the Spring framework: Spring AI client abstraction, ChatClient, ChatModel, EmbeddingModel, VectorStore (pgvector), Retrieval-Augmented Generation (RAG), tool calling / function calling, structured outputs, and the Model Context Protocol (MCP).
