# Contributing to the Spring Boot Learning Track

## Quality & Style Guidelines

1. **Strict Markdown-Only Rule**: Zero non-markdown files. All Java code, XML configurations, and Docker files must be embedded in fenced code blocks.
2. **Template Compliance**:
   - Concept notes MUST strictly follow all 13 sections in `_templates/concept-template.md`.
   - Reference projects MUST strictly follow all 5 sections in `_templates/project-template.md`.
3. **Java Baseline**: Java 21 / 25 LTS syntax (Records, pattern matching, Virtual Threads).
4. **Spring Baseline**: Spring Boot 3.4+ / 4.x, Spring Framework 6.2+ / 7.0, Spring Security 6/7 (Lambda DSL only).
5. **Verified Code**: All examples must compile cleanly with `javac` and execute without unhandled runtime bugs.
