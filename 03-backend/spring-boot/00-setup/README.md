# Module 00: Environment, Tooling & Setup

Welcome to **Module 00: Environment, Tooling & Setup**. This module establishes the technical baseline for modern enterprise Spring Boot engineering, covering JDK installation, build toolchains (Maven and Gradle), Spring Initializr, IDE optimizations, DevTools, Docker Compose service wiring, and migration paths.
