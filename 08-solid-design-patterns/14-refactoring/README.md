# Module 14: Refactoring

Refactoring is the disciplined practice of **improving internal code structure without changing external observable behavior**. This module covers the safe refactoring loop, Fowler's core catalogue, Joshua Kerievsky's *Refactoring to Patterns*, Michael Feathers' legacy Characterization Tests, Branch by Abstraction, IDE automation, and objective design-quality metrics.
