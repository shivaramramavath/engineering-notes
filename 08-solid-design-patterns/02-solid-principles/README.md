# Module 02: SOLID Principles

Welcome to **Module 02: SOLID Principles** of the Software Design & Patterns Curriculum. This module provides an exhaustive, problem-first breakdown of the five foundational principles popularized by Robert C. Martin (Uncle Bob) that govern modern object-oriented and modular system architecture.

## Core Learning Outcomes

By completing this module, you will:
1. Understand how OCP is the ultimate architectural goal, while SRP, LSP, ISP, and DIP serve as the mechanical tools to achieve it.
2. Spot the distinct structural symptoms of each principle violation during code reviews.
3. Master the subtle mathematical and behavioral contract rules of Liskov Substitution (covariance and contravariance).
4. Distinguish between Dependency Inversion (the architectural principle), Dependency Injection (the wiring pattern), and Inversion of Control (the runtime framework mechanism).
5. Apply SOLID pragmatically without falling into the trap of speculative micro-abstractions.
