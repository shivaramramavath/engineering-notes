# C Systems Programming Glossary (`GLOSSARY.md`)

- **ABI (Application Binary Interface):** The low-level interface between compiled binary modules, defining calling conventions, register usage, data type sizes, struct alignments, and symbol mangling.
- **Alignment:** A hardware memory constraint requiring that data of size $N$ bytes be stored at a memory address that is a multiple of $N$.
- **AOS (Array of Structs):** Traditional data layout where entire objects are stored contiguously (`[RGB][RGB][RGB]`). Less friendly for SIMD vectorization.
- **Arena Allocator:** A region-based memory allocator that allocates chunks sequentially by bumping an offset pointer and deallocates all allocations simultaneously in $O(1)$ time by resetting the offset.
- **ASan (AddressSanitizer):** A compiler-assisted instrumentation tool that uses shadow memory to detect buffer overflows, use-after-free, and double-free bugs at runtime.
- **AST (Abstract Syntax Tree):** A hierarchical tree representation of source code structure produced by compiler parsers.
- **Atomic Operation:** An indivisible operation that completes without interruption or interference from concurrent threads, preventing data races.
- **Boundary Tags:** Header and footer tags bracketing heap memory blocks, enabling constant-time $O(1)$ bidirectional coalescing of adjacent free blocks.
- **Branch Predictor:** A CPU execution unit that speculatively guesses the outcome of conditional branch instructions to avoid pipeline stalls.
- **Cache Line:** The smallest unit of data transferred between main memory and CPU caches (typically 64 bytes).
- **False Sharing:** A performance degradation occurring in multi-threaded programs when threads on different cores update independent variables that reside within the same 64-byte cache line, forcing continuous cache invalidation.
- **Incomplete Type:** A type that describes an identifier but lacks information to determine its size (e.g., `struct Foo;`). Enables the opaque pointer handle pattern.
- **LTO (Link-Time Optimization):** Deferring compiler code generation and optimization to link time, enabling interprocedural optimizations and whole-program inlining across translation units.
- **PGO (Profile-Guided Optimization):** A compiler optimization technique utilizing execution profile counters from representative workloads to optimize branch layout and code placement.
- **RAII (Resource Acquisition Is Initialization):** A design pattern where resource lifetimes are strictly tied to variable lexical scope. Emulated in C via `__attribute__((cleanup))`.
- **SOA (Struct of Arrays):** Data layout separating structure members into independent parallel arrays (`[RRR...][GGG...][BBB...]`), maximizing SIMD vector throughput.
- **TOCTOU (Time-of-Check to Time-of-Use):** A race condition vulnerability occurring between the verification of a resource state (e.g., file permissions) and the actual operation on that resource.
- **Translation Unit (TU):** A single C source file (`.c`) along with all header files and code included via the preprocessor (`#include`).
- **Undefined Behavior (UB):** Behavior for which the ISO C standard imposes no requirements. Compilers assume UB never occurs, exploiting it to aggressively optimize or prune code.
- **Vtable (Virtual Method Table):** A table of function pointers stored in read-only memory, enabling runtime polymorphism and dynamic dispatch in procedural C.
