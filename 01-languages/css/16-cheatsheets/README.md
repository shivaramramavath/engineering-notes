## How to Use These Cheatsheets

1. **Syntax Lookups**: Keep open during live coding and PR reviews to verify spec-compliant property syntax and valid token combinations.
2. **Formula Calculations**: Copy-paste fluid typography formulas, specificity arithmetic tables, and contrast calculations directly.
3. **Emergency Debugging**: Use [12-common-bugs-and-fixes.md](file:///e:/Learning/engineering-notes/01-languages/css/16-cheatsheets/12-common-bugs-and-fixes.md) to instantly diagnose rendering anomalies like unexpected horizontal scrolling or misaligned grid items.
