## 2. File Organization
Every project consists strictly of 4 markdown files:
1. `README.md`: Architecture, project overview, design specs, user requirements.
2. `01-design.md`: Design system, color palettes, responsive breakpoint scales, token hierarchy.
3. `02-html-and-css.md`: Complete production HTML and CSS code in fenced markdown blocks.
4. `03-measured-results.md`: Real computed layout properties, bounding box dimensions, and responsive viewport tests.
5. `04-limitations-and-next-steps.md`: Edge cases, progressive enhancements, and future spec adaptations.
