# 03 · Objects and Arrays

Almost everything you store and pass around in JavaScript is an **object** or an **array** (which is a special object). This chapter covers how to create, inspect, copy, transform, search and unpack them.

By the end you can model data with objects and arrays, transform it without accidental mutation, and safely read deeply nested values.
