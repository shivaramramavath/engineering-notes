# JavaScript Engineering Technical Glossary

> A definitive, alphabetical reference (A–Z) defining 100+ formal ECMAScript specification terms, V8 engine internal structures, browser rendering mechanics, and asynchronous primitives.

---

## A

### Abstract Equality (`==`)
The ECMAScript comparison algorithm that performs type coercion via `ToPrimitive`, `ToNumber`, or `ToString` before evaluating equality.

### Abstract Syntax Tree (AST)
A tree representation of the abstract syntactic structure of source code produced by the parser and consumed by bytecode generators (Ignition).

### AbortController / AbortSignal
Standardized DOM and Node.js primitives enabling cooperative cancellation of asynchronous operations (e.g. `fetch`, timers, child processes).

### Allocation Site
The physical location in bytecode where an object or array is instantiated. V8 tracks allocation sites to predict future object shapes and element kinds.

### Asynchronous Iteration
A protocol (`Symbol.asyncIterator`) enabling `for await...of` loops over asynchronous data streams yielding Promises.

### Atomics
A static object providing atomic operations (e.g. `add`, `load`, `store`, `wait`, `notify`) on shared memory buffers (`SharedArrayBuffer`) across worker threads.

---

## B

### BigInt
A numeric primitive type (`typeof x === 'bigint'`) capable of representing arbitrarily large integers beyond `Number.MAX_SAFE_INTEGER` ($2^{53} - 1$).

### Biome
A fast, Rust-based toolchain providing integrated linting and code formatting for JavaScript and TypeScript.

### Bytecode
An intermediate, platform-independent instruction set generated by V8's Ignition interpreter from the AST.

---

## C

### Call Stack
A contiguous LIFO (Last-In, First-Out) memory structure managed by the engine to track active execution context frames.

### Cleanups (Reactivity)
The process of disconnecting an effect from its prior dependencies before each execution to prevent phantom triggers on conditional branches.

### Closure
The combination of a function bundled together with references to its surrounding lexical environment (`[[Environment]]`).

### Critical Rendering Path (CRP)
The sequence of steps browsers take to convert HTML, CSS, and JavaScript into physical pixels on the screen: DOM $\to$ CSSOM $\to$ Render Tree $\to$ Layout $\to$ Paint $\to$ Composite.

---

## D

### Dead Code Elimination (DCE)
An optimizing compiler pass (in Turbofan) that detects and removes instructions that have no observable effect on program output.

### De-optimization Bailout
The emergency reversion of optimized machine code (Turbofan) back to unoptimized bytecode (Ignition) when runtime type feedback invalidates speculative assumptions.

### Destructuring
A syntax allowing extraction of data from arrays or properties from objects into distinct variables using pattern matching.

---

## E

### ECMAScript
The standardized specification (ECMA-262) governing the syntax, standard library, and runtime semantics of the JavaScript language.

### Element Kinds
V8 internal representations of array backing stores categorized by packed vs holey and type (`PACKED_SMI_ELEMENTS`, `PACKED_DOUBLE_ELEMENTS`, `HOLEY_ELEMENTS`). Transitions are strictly one-way towards generic holey types.

### Event Loop
The coordination mechanism that multiplexes synchronous Call Stack execution, Microtasks, browser rendering steps, and Macrotasks across single-threaded runtimes.

---

## F

### Fast / Slow Properties
V8 stores properties in one of three modes: In-Object (fastest, fixed offsets), Normal / Out-of-Object (fast backing array), or Dictionary Mode (slow hash table).

### FinalizationRegistry
A built-in object allowing registration of cleanup callbacks when a targeted object is reclaimed by the Garbage Collector.

---

## G

### Garbage Collection (GC)
Automatic memory reclamation. V8 employs Orinoco, a generational garbage collector utilizing Scavenger (semi-space copying) for Young Generation and Mark-Sweep-Compact for Old Generation.

### Grapheme Cluster
A user-perceived character that may consist of multiple Unicode code points (e.g. base character + emoji skin tone modifiers + zero-width joiners). Segmented via `Intl.Segmenter`.

---

## H

### Hidden Class (Map / Shape)
An internal V8 data structure representing the concrete layout and memory offset indices of an object's properties. Shared among objects with identical property initialization orders.

### Hoisting
The conceptual process during context creation where variable (`var`) and function declarations are allocated into their respective Environment Records prior to statement execution.

---

## I

### Immediately Invoked Function Expression (IIFE)
A design pattern where a function is defined and executed immediately: `(function() { ... })();`. Used historically for module encapsulation.

### Inline Cache (IC)
A bytecode optimization technique where call sites cache the observed Hidden Classes and memory offsets of object properties to bypass hash table lookups.

### Inversion of Control (IoC)
An architectural principle where a framework or container controls the flow of program execution and dependency creation rather than the consuming component.

---

## L

### Layout Thrashing (Forced Synchronous Layout)
A performance bottleneck occurring when JavaScript interleaves DOM style writes with geometry reads (`offsetWidth`, `scrollTop`), forcing the browser to recalculate layout synchronously.

### Lexical Scope
Scoping determined entirely by the physical location of variables and blocks within the source code during author-time.

---

## M

### Macrotask (Task)
Independent discrete turns scheduled on the event loop (e.g. `setTimeout`, `setInterval`, I/O, UI interactions). Exactly one is executed per loop turn.

### Megamorphic IC
An Inline Cache state where a call site has observed 5 or more distinct Hidden Classes. The JIT stops inline checks and falls back to a global hash lookup table.

### Microtask
High-priority asynchronous callbacks (`Promise.then`, `queueMicrotask`, `MutationObserver`) that execute immediately after the current call stack clears and before the browser renders or processes the next macrotask.

### Monomorphic IC
The optimal Inline Cache state where a call site encounters exactly one Hidden Class, allowing compilation to a direct memory pointer read guarded by a single comparison.

---

## P

### Polymorphic IC
An Inline Cache state where a call site has observed between 2 and 4 distinct Hidden Classes, evaluated via a short linear switch table.

### Prototype Delegation
The inheritance model in JavaScript where objects hold a hidden `[[Prototype]]` link to an ancestor object. Unresolved property reads automatically traverse up this chain.

### Proxy
An exotic object wrapping a target object, intercepting low-level operations (get, set, apply, construct) through handler traps.

---

## S

### SameValueZero
An internal equality comparison algorithm used by `Map`, `Set`, and `Array.prototype.includes`. Identical to `===` except that `SameValueZero(NaN, NaN)` evaluates to `true`.

### Small Integer (Smi)
In V8, 31-bit or 32-bit signed integers stored directly inside pointer-tagged registers without allocating heap memory (lowest bit is `0`).

---

## T

### Temporal Dead Zone (TDZ)
The temporal region between the entry into a block scope and the actual statement evaluation of a `let` or `const` variable where accessing the identifier raises a `ReferenceError`.

### ToPrimitive
The abstract ECMAScript operation converting an object into a primitive value using `[Symbol.toPrimitive]`, `valueOf`, or `toString`.

---

## W

### WeakMap / WeakSet
Key-value collections holding weak, un-enumerable references to object or symbol keys. If a key object has no other strong references, it can be garbage collected along with its associated value.

### Worker Threads
Node.js native threads (`node:worker_threads`) allowing isolated parallel JavaScript execution sharing memory via `SharedArrayBuffer`.
