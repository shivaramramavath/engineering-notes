# 01 · Fundamentals

The core building blocks every JavaScript program is made of: how to store values, what kinds of values exist, how they convert, how to combine them, and how to control the flow of execution.

## Reading order

| #   | File                                                                 | You will learn                                          |
| --- | -------------------------------------------------------------------- | ------------------------------------------------------- |
| 1   | [Variables](./01_variables.md)                                       | `var`, `let`, `const`, scope, hoisting basics           |
| 2   | [Data Types](./02_data-types.md)                                     | Primitives, objects, `typeof`, value vs reference       |
| 3   | [Type Conversion and Equality](./03_type-conversion-and-equality.md) | Coercion, truthy/falsy, `==` vs `===`, `Object.is`      |
| 4   | [Operators](./04_operators.md)                                       | Arithmetic, logical, `??`, `?.`, assignment, precedence |
| 5   | [Expressions and Statements](./05_expressions-and-statements.md)     | What produces a value and what does not, ASI            |
| 6   | [Conditionals](./06_conditionals.md)                                 | `if`, ternary, `switch`, guard clauses                  |
| 7   | [Loops](./07_loops.md)                                               | `for`, `while`, `for...of`, `for...in`, labels          |

## Goal

By the end you can declare variables correctly, predict what `typeof`, `==` and `+` will do, and write branching and looping code without the classic beginner traps.
