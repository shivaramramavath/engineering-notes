## How to Use These Cheatsheets

1. **Daily Engineering**: Bookmark `00_syntax-and-operators.md` and `01_arrays-and-objects.md` for fast syntax lookups.
2. **System Design & Asynchrony**: Consult `03_async-and-promises.md` and `04_event-loop-order.md` when diagnosing concurrency or event timing issues.
3. **Debugging & Testing**: Keep `09_testing-commands.md` and `10_devtools-shortcuts.md` open during test authoring and performance profiling.
4. **Code Reviews**: Check `12_common-gotchas.md` for subtle edge cases during peer pull request reviews.
