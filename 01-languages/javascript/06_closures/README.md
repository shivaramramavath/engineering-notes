# 06 · Closures

A **closure** is a function bundled with the variables from the scope where it was created. Closures power callbacks, private state, factories, memoization, currying and most of modern JavaScript's patterns.

| # | File | You will learn |

| 3 | [Closure Pitfalls](./03_closure-pitfalls.md) | Loop bugs, stale values, memory leaks, performance |

## Goal

By the end you can explain what a function "remembers", use closures deliberately to hide state and configure behavior, and spot the classic bugs they cause.
