# 00 · Setup

Before writing real JavaScript you need three things: a clear picture of what the language is, a place to run it, and tools that help you find and prevent mistakes.

## Reading order

| #   | File                                                            | You will learn                            |
| --- | --------------------------------------------------------------- | ----------------------------------------- |
| 1   | [What is JavaScript](./01_what-is-javascript.md)                | ECMAScript, engines, versions, TC39       |
| 2   | [Runtimes: Browser and Node](./02_runtimes-browser-and-node.md) | Where JS runs and what each runtime adds  |
| 3   | [npm and Package Managers](./03_npm-and-package-managers.md)    | `package.json`, installs, scripts, semver |
| 4   | [DevTools and Debugging](./04_devtools-and-debugging.md)        | Console, breakpoints, stack traces        |
| 5   | [Tooling](./05_tooling.md)                                      | Git, ESLint, Prettier, Vite, editor setup |

## Goal

By the end you can run a script in the browser and in Node, install a package, debug with breakpoints, and have a project with linting and formatting.

## Quick check

```bash
node -v          # 20 or newer recommended
npm -v
git --version
```
