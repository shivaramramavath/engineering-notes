# 02 · Functions

Functions are the main unit of reuse in JavaScript. They are also **values**: you can store them in variables, pass them as arguments, and return them from other functions.

| 8 | [Recursion](./08_recursion.md) | Base case, call stack, memoization, trampolines |

## Goal

By the end you can choose the right function form, design clean signatures, and use callbacks and higher-order functions confidently.
