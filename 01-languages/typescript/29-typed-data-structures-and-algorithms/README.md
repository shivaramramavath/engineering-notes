# Module 29: Typed Data Structures and Algorithms

Welcome to the **Typed Data Structures and Algorithms** module of the TypeScript engineering curriculum. This module bridges computer science fundamentals and advanced TypeScript type systems: pointer-based data structures, heaps, graphs, memory-bounded caches, probabilistic filters, and compile-time type-space algorithms.
